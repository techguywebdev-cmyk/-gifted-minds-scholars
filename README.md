# Gifted Minds Scholars

Website for **Gifted Minds Scholars**, a Pre-K–5th grade tutoring program in Loganville, Georgia (in person and online), founded by Mrs. Wendy Bonnick. It's an educational tutoring program of BACB21Co.

It's a fast static site with no framework, no dependencies and no page builder.

## Structure

```
config.json            ← site URL, phone, email, hours, form endpoint (edit here first)
build.mjs              ← zero-dependency build: src → dist
src/pages/             ← one HTML file per page (JSON header between --- lines)
src/pages/programs/    ← program pages (generated by scripts/gen_programs.py)
src/partials/          ← logo + icon sprite
src/assets/            ← CSS, JS, self-hosted fonts, images
src/public/            ← robots.txt, llms.txt, manifest, favicons
scripts/               ← one-off generators (program pages, share image + icons)
```

## Commands

```bash
node build.mjs              # build to ./dist
npx serve dist              # preview locally
node scripts/make-images.mjs  # regenerate og-image + icons (needs Playwright)
```

## Deploy

- **Vercel:** import the repo. `vercel.json` sets the build command and the `dist` output folder.
- **Netlify:** import the repo. `netlify.toml` is already configured.

Before launch:
1. Set `siteUrl` in `config.json` to the real domain. Canonicals, sitemap, schema and llms.txt all use it.
2. Set `formEndpoint` (Formspree, Web3Forms, Basin…) so enrollment inquiries arrive by email. While it's empty, the form opens the visitor's email app with everything filled in.
3. Submit `https://<domain>/sitemap.xml` in Google Search Console and Bing Webmaster Tools.
4. Create a Google Business Profile for "Gifted Minds Scholars" in Loganville, GA, using the same name, phone and city as the site.

## SEO / AEO built in

- Unique titles, meta descriptions, canonicals, Open Graph and Twitter cards on every page
- JSON-LD graph: LocalBusiness + EducationalOrganization, Person (founder), Service (per program), FAQPage, BreadcrumbList, WebSite, plus opening hours and geo
- An answer-first summary at the top of each page, question-style H2s, an FAQ page and a `speakable` markup selector
- `llms.txt` (facts for AI assistants), and `robots.txt` that explicitly allows AI search crawlers
- Self-hosted fonts, preloaded hero image, responsive WebP and lazy-loaded images, so Core Web Vitals stay fast
- Semantic HTML, skip link, keyboard-friendly navigation and reduced-motion support
- A local landing page (`/tutoring-loganville-ga/`) and Parent Resources articles with BlogPosting schema
- An image sitemap, `llms-full.txt` (the full site text for AI assistants) and an IndexNow key file
- Config switches for Search Console and Bing verification, plus GA4
